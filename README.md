# TruePage Scan — cloud OpenCV + ChatGPT MCP server

This is an **implementation starter**, not a pre-deployed cloud service. All transformations operate on existing image pixels. It never generates or rewrites printed text.

## What is included

- `scan_engine.py`: orientation, page split, perspective warp, conservative optional enhancement, optional manual corners.
- `server.py`: protected web uploader, temporary PNG result storage, MCP tools `scan_image_base64` and `get_scan_download`.
- `Dockerfile`, `render.yaml`: portable Docker image and Render Blueprint.
- `plugin-template/` and `tools/make_plugin.py`: create a private ChatGPT plugin ZIP **after** the server is live and you know its actual hostname.
- `tests/`: regression tests for OpenCV processing.

## Step 1: Test on your computer (optional)

Requires Python 3.11+ and internet to install dependencies.

```bash
python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python -m pytest tests  # additionally install pytest if necessary
export SCAN_ACCESS_KEY='long-random-secret'  # Windows PowerShell: $env:SCAN_ACCESS_KEY='...'
uvicorn server:app --host 127.0.0.1 --port 8000
```
Open http://127.0.0.1:8000/ and enter the access key.

## Step 2: Deploy on Render

1. Upload the contents of this folder to a **private GitHub repository** (not the ZIP itself).
2. Log in at [Render](https://dashboard.render.com/) and choose **New → Blueprint**, selecting the GitHub repository containing `render.yaml`. Render supports Docker web services and health checks as configured in the Blueprint.
3. Set `PUBLIC_BASE_URL` to the actual HTTPS URL of the service (e.g. `https://your-assigned-name.onrender.com`). `SCAN_ACCESS_KEY` is randomly generated by Render. **Keep it secret**.
4. Verify `https://YOUR-REAL-HOST/health` returns `{ "status":"ok", ... }` and open the home page to scan your photograph.

**Important**: The Render instance's local filesystem is ephemeral on many plans. PNG downloads are temporary and may disappear sooner on redeployment/restart. In this starter, files expire after 12 hours. For long-term storage/multi-instance deployment, add persistent object storage (e.g. private S3 bucket) and authenticated downloads.

## Step 3: Generate your ChatGPT MCP plugin package

After your HTTPS URL works:

```bash
python tools/make_plugin.py https://YOUR-REAL-HOST
```

This creates `truepage-scan-plugin.zip`, containing a valid `plugin.json`, `skills/truepage-scan/SKILL.md`, and `mcp.json` pointing to your service's `/mcp/` endpoint. Save/install it using Plugin Creator in ChatGPT.

**MCP authentication caveat:** By default `SCAN_ACCESS_KEY` protects `/mcp/` with a Bearer token. The plugin manifest does **not** contain that secret. You will need to configure compatible Bearer support in your MCP client/host or put the endpoint behind a properly authenticated OAuth-compatible gateway. A private plugin's name alone does not authenticate the server. Do not put API keys in `mcp.json`, do not expose the MCP endpoint publicly unless you accept abuse risks, and do not claim that the connection works until it's tested.

## Using the service

- Upload one photo in the web UI. The default processes the **left page** of a two-page spread. The button to scan the **right page** appears only after a successful left scan.
- If a page is upright and single, set `Single page` in both selection fields.
- Auto orientation assumes portrait photos of two-page spreads are rotated counterclockwise; if that is wrong select explicit rotation.
- For difficult pages supply four normalized `[x,y]` corner coordinates TL/TR/BR/BL **after rotation**, e.g. via the `/api/scan` multipart field `corners_json`.
- Open `/health` to confirm deployment readiness; actual scan correctness must still be visually checked.

### Command-line API example

```bash
curl -X POST https://YOUR-REAL-HOST/api/scan \
  -H 'Authorization: Bearer YOUR_ACCESS_KEY' \
  -F 'file=@book-photo.jpg' -F page=left -F spread=two -F rotation=auto
```

The result is JSON containing a temporary PNG `download_url` and warnings.

## Accuracy and limitations

This preserves source pixels (with geometric resampling). It cannot recover illegible characters, physically hidden parts or unflatten fully curved sheets with a simple 4-corner transform. It can also make imperfect guesses about page borders; review the output and override the corners rather than allow clipped text. Enlarging an image **does not** add real optical resolution. Do not use generative image models as the backend for fidelity-critical scans.

## Security checklist before production

- HTTPS only, strong `SCAN_ACCESS_KEY`, no secrets committed to GitHub.
- Add proper OAuth-compatible MCP authentication if required by ChatGPT's connection flow.
- Add upload rate limits and an object store for higher traffic.
- Use private GitHub repo and check hosting privacy/data retention requirements.
- Do not use this demo service to process confidential documents before reviewing authorization and storage.
